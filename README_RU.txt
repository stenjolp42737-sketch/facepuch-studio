FACEPUCH STUDIO 4.8 — Supabase edition

Что сохранено:
- Исходный визуальный стиль, цвета, эффекты снега и музыка из 4.7.
- Каталог Rust / Rust 2 без картинок.
- Существующие вкладки админ-панели и функции профиля.

Что подключено к Supabase:
- Общая лента новостей и изображения к новостям.
- Общий логотип, цвет/картинка фона и фоновое MP4-видео.
- Общие сообщения и отзывы; сообщения видит только владелец, отзывы можно модерировать.
- Защищённая авторизация владельца через Supabase Auth.
- Файлы сайта хранятся в публичном bucket site-media; загрузка/удаление разрешены только владельцу.

ВАЖНО — ПОРЯДОК НАСТРОЙКИ
1. В Supabase открой Authentication > Users > Add user.
2. Создай свой аккаунт владельца (email + пароль) и подтверди его, если панель попросит.
3. Скопируй UUID созданного пользователя из списка Users.
4. Открой SQL Editor. Выполни весь файл setup_supabase.sql.
5. В конце файла есть отдельная команда-комментарий. Скопируй INSERT, замени OWNER_USER_UUID на свой UUID и выполни её отдельно.
6. Убедись, что bucket site-media существует и он Public. Лимит 50 MB можно оставить.
7. Загрузи на хостинг index.html, style.css и script.js из этой папки. SQL-файл на сайт загружать не нужно.
8. Открой сайт, нажми АДМИН и войди с email/паролем, созданными в Supabase.

БЕЗОПАСНОСТЬ
- В код встроен только sb_publishable_ ключ — это публичный ключ.
- Никогда не вставляй sb_secret_ или service_role в сайт и не отправляй их никому.
- Ты ранее отправил sb_secret_ в чат. Отзови его в Supabase Settings > API Keys и не используй снова.
- Не публикуй email/пароль владельца и UUID в открытых местах.

ОГРАНИЧЕНИЯ
- Bucket ограничен 50 MB на файл, поэтому MP4 должен быть не больше 50 MB.
- Музыкальный пользовательский файл из старой версии оставлен в локальном хранилище браузера, чтобы не менять существующую музыкальную функцию. Остальные общие настройки/медиа синхронизируются через Supabase.
- Если старый SQL в проекте уже создавал политики с другими именами, эти политики могут сосуществовать; перед публичным запуском проверь Policies в Supabase.
